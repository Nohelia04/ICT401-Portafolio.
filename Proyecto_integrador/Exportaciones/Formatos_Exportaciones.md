# Formatos y Exportación del Proyecto: TDBG (Tapa Dispensadora para Bolsas de Granos)

Para garantizar la correcta documentación, interoperabilidad y futura fabricación de los componentes del sistema **TDBG** (Collar, Tapa roscada y Tapón con asa), el modelo diseñado en Autodesk Fusion fue exportado en cuatro formatos estándar de la industria:

* **PDF (Portable Document Format):** Formato estándar de documentación utilizado para la revisión visual, distribución y entrega formal de los planos técnicos en 2D (*Drawings*), manteniendo intactas las cotas, tolerancias y el cajetín institucional.
* **DXF (Drawing Exchange Format):** Archivo vectorial de intercambio de geometría en 2D, indispensable para asegurar la compatibilidad con sistemas de corte láser, mecanizado CNC o trazado computarizado.
* **STL (Stereolithography):** Formato de malla tridimensional triangulada optimizado específicamente para el laminado (*slicing*) y la fabricación de prototipos físicos mediante impresión 3D (manufactura aditiva).
* **STEP (Standard for the Exchange of Product Data):** Formato neutral de transferencia de datos CAD en 3D que conserva la geometría sólida exacta, asegurando la interoperabilidad paramétrica entre distintas plataformas de ingeniería sin pérdida de calidad.

---

### Resumen de Aplicación en el Proyecto

| Formato | Tipo de Geometría | Uso Principal en el Proyecto TDBG |
| :--- | :--- | :--- |
| **PDF** | 2D  | Entrega y lectura de planos formales y lista de partes (BOM). |
| **DXF** | 2D  | Transferencia de perfiles planos para manufactura asistida. |
| **STL** | 3D | Impresión 3D de prototipos funcionales para pruebas de ajuste. |
| **STEP** | 3D | Respaldo universal del ensamblaje e intercambio entre software CAD. |
